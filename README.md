##### **Build a CSV Data Processor**



###### **Description**

The CSV Data Processor is a Python project that reads employee or sales data from a CSV file and calculates useful statistics such as totals, averages, highest values, and record counts.



###### **Objective**

To learn practical CSV file processing using Python and handle missing or invalid data.



###### **Technologies Used**

\- Python

\- CSV module



###### **Features**

\- Reads data from a CSV file.

\- Counts the total number of records.

\- Calculates the sum and average of numeric values.

\- Finds the highest numeric value in each column.

\- Handles missing or invalid values.

\- Displays a summary report.



###### **Project Files**

\- csv\_processor.py – Python program for processing CSV data.

\- employees.csv – Sample input dataset.

\- README.md – Project documentation.



###### **How to Run**

1\. Install Python on your computer.

2\. Save the program as `csv\_processor.py`.

3\. Create an `employees.csv` file in the same folder.

4\. Open the terminal and run: python csv\_processor.py

5\. Enter the CSV file name when prompted.



###### **Sample Input**



Employee,Department,Salary

Ravi,IT,30000

Priya,HR,35000

Kiran,IT,40000

Anu,Sales,25000



###### **Expected Output**

The program displays the total number of records and calculates the total, average, and highest value for numeric columns such as Salary.



###### **Learning Outcomes**

\- Understanding CSV file handling in Python.

\- Using Python's built-in `csv` module.

\- Performing calculations on numeric data.

\- Handling missing and invalid values.

\- Organizing code using functions.



###### **Conclusion**

This project helped me practice reading CSV files, processing datasets, calculating useful statistics, and generating a summary report using Python.
